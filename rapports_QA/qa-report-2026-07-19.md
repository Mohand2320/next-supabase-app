## Analyse des causes racines

### 1. API `/api/rdv` lente (~1.9s)
- **Cause** : Requête Supabase non optimisée (`select *` + jointures manquantes + pas d'index sur `date_rdv`)
- **Module responsable** : `src/app/api/rdv/route.ts` + `src/services/rdv.service.ts`
- **Impact** : Calendrier lent à charger, UX dégradée
- **Fix** : Ajouter index DB, sélectionner colonnes spécifiques, paginer

### 2. Auth Supabase lente (~1s)
- **Cause** : Round-trip réseau vers `gqfkuylqsjphanrcfbpx.supabase.co` (région distante) + JWT verification
- **Module responsable** : `src/lib/supabase/server.ts` (middleware + Server Components)
- **Impact** : Tout appel serveur authentifié ralenti
- **Fix** : Activer Supabase Edge Functions / régionaliser projet, ou cache session courte durée

### 3. Middleware déprécié Next.js 16
- **Cause** : Code écrit pour Next.js 15 middleware API
- **Module responsable** : `src/middleware.ts`
- **Impact** : Warning build, risque cassure Next 17
- **Fix** : Réécrire selon nouvelle convention `NextResponse.next()`

### 4. Warnings librairies tierces (React 19)
- **Cause** : `react-odontogram@0.5.6` et `framer-motion@12` pas pleinement compatibles React 19 strict mode
- **Impact** : Noise dans console dev, aucun bug prod
- **Fix** : Upstream PR ou wrapper / suppression StrictMode pour ces composants
